### Docker Compose

Первая инструкция в README использовала только команду:

```bash
docker compose up
```

В папке с кириллицей Docker Compose не смог автоматически определить имя проекта и
вернул ошибку `project name must not be empty`.

Исправление: в README добавлена команда с явным именем проекта:

```bash
docker compose -p kvitto-payments up --build
```

### Идемпотентность

Обычная последовательность `SELECT -> INSERT` недостаточна для конкурентных
запросов. Два запроса с одинаковым ключом могут одновременно не найти существующую
запись.

Исправление: поле `idempotency_key` имеет ограничение `UNIQUE`. При конкурентной
вставке сервис получает `IntegrityError`, выполняет `rollback()` и читает уже
созданный платёж.

### График рассрочки

При обычном делении сумма платежей может не совпасть с итоговой суммой из-за остатка
от деления.

Исправление: используется `divmod(amount, months)`. Лишние копейки добавляются к
первым платежам графика.
