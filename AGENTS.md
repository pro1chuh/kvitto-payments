# Правила проекта

- Использовать Python 3.11+, FastAPI, SQLAlchemy 2 и Pydantic 2.
- Деньги хранить и передавать только как `int` в копейках.
- Не использовать `float` или `Decimal` в `app/`.
- Не добавлять функциональность вне технического задания.
- Бизнес-логику размещать в `app/services/`; роутеры оставлять тонкими.
- Не менять заданные форматы ответов API.
- Не хранить секреты и `.env` в репозитории.
- Перед завершением запускать `ruff check .` и `pytest -q`.
- Проверять идемпотентность через UNIQUE и обработку `IntegrityError`.
- Статусы менять условным `UPDATE`, не через блокировки SQLite.
